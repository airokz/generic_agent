# Skills

A skill is a reusable procedure for one kind of task. Keep one folder per skill, with a `SKILL.md` containing YAML `name` and `description`, followed by instructions.

Start with [example-skill/SKILL.md](example-skill/SKILL.md) for help creating a skill and finding existing ones. Skill names use hyphens to match the shared format.

Keep rules in `rules/`, background in `context/`, and progress in `memory.md`. Add supporting scripts or references only when needed. Check a third-party skill's contents, license, and tool requirements before using it.
