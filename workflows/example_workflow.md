# Example workflow: prepare a short brief

**Use when:** a task calls for a concise summary of supplied materials.

1. Read `memory.md`, the task, and applicable rules.
2. Review relevant materials in `inputs/` and `context/`. Identify missing information.
3. Draft the brief using `templates/example_template.md`.
4. Check each material claim against its source and confirm the requested scope is covered.
5. Save the draft as `output/brief.md` and update `memory.md` with the result and next step.

Preserve an existing brief if a new version is needed. If no new materials or instructions have arrived, report that instead of repeating completed work. Preparing the brief does not authorize sending or publishing it.
