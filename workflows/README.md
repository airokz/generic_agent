# Workflows

Save a short process here when it becomes repeatable:

1. Trigger and desired result.
2. Required inputs and applicable rules.
3. Steps, linking relevant skills and templates.
4. Checks and any human review before external actions.
5. Output location and state update.
6. What to do with missing inputs, failures, or a repeated run.

Keep the process map here and detailed task procedures in skills. Start with manual runs; a workflow file does not enable a schedule or integration.
